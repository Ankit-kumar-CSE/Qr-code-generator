## Simple QR Code Generator





A lightweight Python script that allows users to generate custom QR codes from any URL or text input. This project utilizes the qrcode library to transform user input into a .png image file stored locally.





#### 🚀 Features



Simple Command Line Interface: Just run the script and paste your URL.



Instant Generation: Quickly creates a high-quality QR code image.



Customizable: Built using the qrcode Python library, allowing for future expansions like custom colors or box sizes.







#### 🛠️ Requirements



Before running the script, ensure you have the qrcode library and Pillow (for image processing) installed:



 	Bash:-

 	pip install qrcode\[pil]





 

#### 📂 Project Structure



Qrcode\_generator.py: The main Python script.



Output: By default, the script saves the image to a specified directory (e.g., D:\\Python\\Projects\\qrcode.png).



Note: Remember to update the file\_path variable in the script to a directory that exists on your computer before running!







#### ⚙️ How to Use



1. Clone the repository:

 	Bash:-

 	git clone https://github.com/Ankit-kumar-CSE/qr-code-generator.git

2\. Run the script:

 	Bash:-

 	python Qrcode\_generator.py

3\. Enter your URL: Type or paste the link you want to convert.



4\. Check your folder: Your QR code will be saved as qrcode.png.
